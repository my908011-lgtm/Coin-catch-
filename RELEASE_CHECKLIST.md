# Coin Catch release checklist

This folder is a playable web/PWA prototype, not a verified Android release build.

## Before launch
- [ ] Test on real Android phones and tablets; check touch controls, timer, score, and restart
- [ ] Test offline behavior after first load
- [ ] Check accessibility, performance, crashes, and screen sizes
- [ ] Replace template privacy policy with publisher-reviewed accurate policy and host it publicly
- [ ] Prepare screenshots, feature graphic, app icon, store description, support email
- [ ] Create Android wrapper/build and generate signed AAB using a suitable Android toolchain
- [ ] Keep signing keys secure; never share passwords or upload credentials into chat
- [ ] Play Console account must be owned/managed by eligible adult where required
- [ ] Complete any required closed test and policy declarations applicable to the account
- [ ] Submit for Google Play review; approval and date are not guaranteed

## Monetization
This prototype has no payouts, betting, cash prizes, ads, or purchases. Do not promise income. If monetization is added, ensure it is age-appropriate and policy-compliant, with a parent/guardian overseeing any required account or payments.
